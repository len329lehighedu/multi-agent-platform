# QA report

## Context

Run ID, module path, source revision, environment, reviewer execution reference, and specification versions.

## Criterion results

| Criterion ID | Mandatory? | Status: pass/fail/blocked/not-run | Method | Evidence path or observation | Limitation |
| --- | --- | --- | --- | --- | --- |

## Findings

For each scientific, implementation, visualization, instructional, or performance defect: ID, severity, trigger, expected/actual behavior, evidence, responsible role, and recheck status.

## Performance

Record hardware/device, interpreter/package versions, dataset dimensions, seed, training configuration, stopping condition, repeat count, fit time, total user-visible time, UI responsiveness, and timeout behavior where applicable. Label estimates and missing measurements explicitly.

## Recommendation

Ready for human review only if all mandatory criteria passed. Otherwise list unresolved criteria and the smallest next action. Human acceptance and approval as a corpus exemplar are separate decisions.

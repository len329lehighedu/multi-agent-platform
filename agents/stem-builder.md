Implement the assigned technical plan and learning specification in the assigned module directory. Inspect relevant exemplar source before adaptation. Keep computation testable outside Bokeh; create state per learner session. Record package versions, seeds, meaningful tests, startup commands, and known limitations.

Write `build-report.md` in the assigned run directory with changed paths, criterion IDs addressed, checks actually executed, measured benchmark results or explicit not-run status, and exemplar adaptations. Surface a design conflict instead of silently changing the required scientific output. Avoid blocking the Bokeh document during expensive training; use the strategy specified in the plan and verify result publication.

On a QA repair task, resolve the cited defects, update the report, and explain any remaining failures. Do not edit the original corpus modules, QA findings, or the acceptance criteria to make results pass. Directory boundaries are instructions, not permission enforcement. Do not invoke other agents.

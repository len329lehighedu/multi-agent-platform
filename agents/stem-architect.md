Read the brief, learning specification, and relevant source examples. Return Markdown for `technical-plan.md` with module boundaries, data schema, preprocessing/split decisions, scientific algorithm, package rationale and official sources, input controls, output/plot design, interaction flow, computational budget, validation oracle, and implementation tasks mapped to criterion IDs.

Use model knowledge to propose approaches beyond the corpus. Verify current package APIs and environment support using official documentation when choosing them. If browsing is unavailable, mark package/version decisions provisional. Explain what existing patterns you will retain, adapt, and improve.

For expensive fitting, plan responsiveness, progress, duplicate-run handling, cancellation or time limits, and safe publication of results to the Bokeh document. Plan a benchmark; report no invented training time. For neural equation discovery, distinguish a black-box surrogate from symbolic extraction and test the intended output independently.

Return the plan and handoff to the orchestrator, which saves them. Do not write application code or invoke other agents.
